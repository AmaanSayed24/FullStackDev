Introduction
This repository contains 12 practical lab exercises completed as part of the Full Stack Development course.  
The labs cover backend programming with Node.js & Express, module usage, asynchronous programming, database ORM concepts using Sequelize, and frontend development using React, followed by frontend-backend integration.


The purpose of this journal is to document:
- What was done in each lab
- Concepts practiced
- Tools and libraries used
- Outcomes and understanding gained  


Lab-Wise Work Journal

Lab 1 — Node.js + Express Basics
- Installed Node.js and initialized project using `npm`.
- Created a basic Express server.
- Understood request and response handling.
- Output: Simple web server returning a text response.

Concepts: Node execution, Express routing, server setup.



Lab 2 — Using Lodash Utility Library
- Installed Lodash: `npm install lodash`
- Used Lodash functions such as `_.chunk`, `_.sortBy`.
- Understood how third-party modules simplify logic.

Concepts: Node module usage, external package import.



Lab 3 — Error Handling, Callbacks & Event Emitters
- Implemented custom error handling in Node.js.
- Created asynchronous callbacks.
- Created and triggered events using `EventEmitter`.

Concepts: Asynchronous JS, callback patterns, event-driven architecture.



Lab 4 — Reminder Application
- Built a reminder app where user sets reminders.
- Used **setTimeout** to trigger reminders.
- EventEmitter used to generate notification events.
- Express used to handle reminder input.

Concepts: Timers in JS, event emitters in real use, Express routing.



Lab 5 — Routing & Streams (with Pipe)
- Created multiple Express routes.
- Read file streams and piped output to response.
- Learned advantages of streaming large data instead of loading into memory.

Concepts: Express routing, Node streams, `.pipe()` method.



Lab 6 — Cron Jobs
- Installed and used `node-cron`.
- Scheduled tasks to run at fixed intervals (e.g., every minute / daily).
- Used console logging & file writing to confirm execution.

Concepts: Automated task scheduling, cron syntax.



Lab 7 — Sequelize Connection Setup
- Installed Sequelize and database drivers.
- Configured database connection.
- Tested sync with database.

Concepts: ORM introduction, DB connection mapping.



Lab 8 — User Model & Queries
- Created user model (fields, datatypes).
- Performed CRUD operations using Sequelize.
- Tested using Node scripts / API routes.

Concepts:Schema modeling, query execution, model operations.



Lab 9 — Sequelize Model Associations
- Created relationships like:
  - One-to-One
  - One-to-Many
  - Many-to-Many
- Used `.belongsTo()`, `.hasMany()`, `.belongsToMany()`.

Concepts: Relational mapping using ORM.



Lab 10 — React Setup
- Installed React using `npx create-react-app`.
- Understood folder structure and start scripts.
- Displayed sample UI text.

Concepts: Use state,Use effect.



Lab 11 — Creating Components (Home, About, Contact)
- Created functional components.
- Connected them using routing (`react-router-dom`).
- Practiced passing props and rendering UI.

Concepts:Components, props, JSX, React Router.



Lab 12 — Frontend & Backend Integration
- Connected React UI to Express backend using fetch/axios.
- Displayed dynamic data on frontend.
- Successfully demonstrated MERN communication workflow.

Concepts:Async function .





 Conclusion

This lab journal reflects the complete journey from backend fundamentals to full-stack integration.The step-by-step lab progression helped in building real development skills useful in modern web application development.
